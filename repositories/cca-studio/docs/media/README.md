# MemoryOS Studio media manifest

This directory contains public MemoryOS v1.2 release media. Historical MemoryOS
1.1 demonstrations, milestone captures, raw source frames, and superseded
pre-v1.1 screenshots are not included in the corrected v1.2.1 source archive.

## Release media

- `memoryos-v1.2-demo.gif` is the canonical GitHub demonstration produced for MemoryOS
  v1.2.0.
- `memoryos-v1.2-demo.mp4` is the canonical full-quality release demonstration produced
  for MemoryOS v1.2.0.
- The three `memoryos-v1.2` screenshots in `../screenshots/` are real production
  captures selected from the official v1.2 recording.

## Historical media boundary

Historical MemoryOS 1.1 media and capture inputs are not distributed in
v1.2.1. Their names may remain in milestone records as non-linking provenance
text, but they must not be used as current-release evidence.

## Retention rules

1. Every current release screenshot, GIF, or video must have an inbound documentation
   reference.
2. A historical filename must not be presented as a link unless its target is
   tracked in the release.
3. Temporary browser, encoder, and generated-work directories are not release
   artifacts.
4. File extensions must match encoded media formats.
