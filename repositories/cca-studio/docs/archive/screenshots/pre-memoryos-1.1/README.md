Reflection presentation explorations from before the final MemoryOS 1.1
release-candidate surface.

release screenshots, are not referenced by the product README, and must not be
used to substantiate MemoryOS 1.1 behavior. Current screenshots live in
[`../../../screenshots/`](../../../screenshots/) and are indexed by the
[Studio documentation](../../../README.md).
