# Conformance Generator compatibility seam

`ConformanceGenerator` reserves an IM-001 public boundary. It is not part of
the IS-002 pipeline and does not create conformance suites, execute tests,
certify implementations, or define the independent `cca-conformance`
repository.

The MO-1208 `cca-conformance` suite is an independent assessment harness and
does not activate or redefine this compiler compatibility seam.
