# Final Phase 2C native witnesses

These are finite engineering drivers, never shipped in the readiness production package and never reachable from public CLI/API options. They use the pinned Windows Node runtime and `helperLaunchSpecification()` for every native helper invocation. No caller-selected PowerShell executable, script, policy, command, or environment is accepted.

- `helper-filesystem.mjs` exercises actual native identities, wire framing, input bounds, publication slots, and Windows filesystem negatives. The optional short-alias probe in its initially executed bytes did not run; `filesystem-supplement.mjs final-path` independently covers the real alias and canonical path.
- `filesystem-supplement.mjs` records narrowly scoped additional native checks. The first ReadAttributes-only ACL fixture did not establish access denial and is preserved as a failed fixture; its original ACL was restored exactly. It is not accepted access-denial evidence.
- `deadlines.mjs` uses real monotonic time, fixed 5000/10000/20000 ms budgets, actual native helpers, and actual worker threads. Its only timing seams hold stdin EOF or defer the test child's requested termination so a genuine late response can arrive. Every response byte remains native. Helpers which are killed without a validated response remain conservatively unconfirmed in product cleanup state; the external process observer separately records actual termination and no survivors.
- `timed-worker.mjs` supplies canned engineering result bytes after a real delay or real busy loop. It provides no 2A/2B semantic certification. `deadlines-remaining.mjs` was used only to continue five cases after the diagnosed aggregate timing fixture was corrected. Final acceptance runs the complete `deadlines.mjs` campaign against final production bytes.
- `environment.mjs` tests actual fixed-helper and worker isolation under synthetic poison, actual CLI startup refusal, and final-source guard rejection. Its preload/import cases use only `node:path`; its loader source is a fixed empty module. Inspector/debug activation is checked at the guard without opening a network listener; actual CLI additionally receives non-listening inspector configuration. `environment-worker.mjs` proves an actual worker receives empty environment/execArgv and frozen memory limits.

Native deadlines are run through the existing external `mo1307-phase2c-resumed/observe-processes.ps1` observer. That observer is excluded from product role counts, binds observed process creation identities, and does not terminate processes. Sampling is supplemental to production ownership/transition guards.

All drivers stop at the first unexpected result, write raw attempt evidence, and do not retry. Prior failed/stopped attempts and exact source snapshots stay preserved. The final timing/environment drivers bind every production `.mjs` module, the fixed helper, and CLI entry before and after execution. Receipt paths live only under `evidence/mo1307/phase2c-final/` and test fixtures live only under the resumed worktree's ignored `.cache/mo1307-final-native/`.
