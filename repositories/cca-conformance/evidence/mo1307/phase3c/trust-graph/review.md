- Graph PASS. - Determinism PASS. Nonsemantic private claim order and public input object insertion order preserve results. Reversed manifest arrays reject because sorted array order is part of the public contract. Fresh public API calls preserve exact result bytes and both digests.
- Result/proof PASS. Public verifyReadiness rejects independently tampered gate vector, blockers, CNE, qualifications, history, provider state, readiness, candidate, profile, stage, graph, normalized authority, audit and human-action vector even after recomputing outer readiness/proof hashes. Separate digest-only mutations and stale proof against a metadata-recomputed result reject. Some mutations are schema/identity-invalid, while the structurally valid changed lists/readiness/audit require original-input recomputation; they are not interchangeable proofs of one layer.

The trust boundary deliberately ends at the independently chosen operator pin. Explicitly authorizing a new root over new opaque legacy source bytes can preserve normalized readiness while changing raw proof. This is expected under Freeze sections 5-8: production does not prove a test ran, parse arbitrary legacy statements, authenticate the reviewer, or police future-reference prose. The test named "new independent reviewed source bytes may preserve readiness but must change raw proof" checks this distinction. It does not claim untrusted evidence can replace the fixed root.
